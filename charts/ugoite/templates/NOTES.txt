The Ugoite Helm chart is a preview of the single-image runtime used by
docker-compose.release.yaml.

Port-forward the service locally (for release name {{ .Release.Name }}):

  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "ugoite.serviceName" . }} 8000:{{ .Values.service.port }}

Then open:

  Browser UI login: http://127.0.0.1:8000/login
  Backend API: http://127.0.0.1:8000

Click "Continue with Local Demo Login" to reach /spaces.

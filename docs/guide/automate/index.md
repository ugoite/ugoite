The old automation hierarchy has been retired. The CLI is a surface for
Knowledge tasks, not a separate user journey.

- Start with [Use Ugoite](../../use/index.md) to choose an outcome.
- Read the [CLI Reference](../../reference/cli.md) for modes, authentication,
  output conventions, and command families.
- Run `ugoite <command> --help` for the exact installed command contract.

Agent principals and service-account workflows remain future design material;
they are not shipped v0.1 capabilities.

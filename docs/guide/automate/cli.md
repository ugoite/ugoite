The CLI documentation has moved to the task-first information architecture.

- For Space, Form, Entry, Asset, Search, and Revision workflows, use [Use
  Ugoite](../../use/index.md).
- For endpoint modes, authentication, output conventions, and command families,
  use the [CLI Reference](../../reference/cli.md).
- For exact flags, arguments, fields, and exit behavior, run
  `ugoite <command> --help` for the installed version.

This page remains as a compatibility path for existing links.

This legacy guide is retained as a compatibility path. The canonical browser
workflow is the [Quickstart](../../get-started/quickstart.mdx), which starts at
the Space and follows the same Knowledge journey as the CLI.

For focused tasks, use these canonical pages:

- [Create a Form](../../use/forms.mdx)
- [Create and Edit Entries](../../use/entries.mdx)
- [Search and Query](../../use/search.mdx)
- [Revisions and Recovery](../../use/revisions.mdx)

In the browser, open **Forms**, select the Form you want to use, and choose
**New Entry**. The browser is currently server-backed; the Space remains the
durable Knowledge authority.

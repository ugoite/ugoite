This is the beginner path. It explains the one idea that shapes everything in
Ugoite—the operator-owned **Space**—then gets a server running and walks through
the first browser Entry.

## Follow this order

1. Read [Core concepts](concepts.md) to understand Spaces, Forms, Entries,
   Assets, revisions, and derived data.
2. Run the [container quick start](container-quickstart.md) for the smallest
   release-style deployment.
3. Create the [first browser Entry](browser-first-entry.md) and identify the
   main browser surfaces.

## After the first run

- For a source build, continue with [Develop Ugoite](../develop/index.md).
- For a production-shaped deployment, continue with
  [Deploy Ugoite](../deploy/index.md).
- For backups, upgrades, and identity administration, continue with
  [Operate Ugoite](../operate/index.md).

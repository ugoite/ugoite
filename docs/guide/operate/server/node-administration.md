> Future/reference workflow. OIDC and account administration are not supported
> v0.1 capabilities.

This page intentionally does not document operational Node administration
commands. The supported v0.1 source of truth is the operator-owned Space
directory; do not edit authorization or identity JSON by hand. Future server
administration must define its shipped authentication and recovery contract
before this page becomes an operator guide.

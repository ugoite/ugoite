This group covers the server as a running node: determine whether it is healthy,
understand the Node administrator boundary, and perform backups or upgrades
without confusing portable Space storage with node-local recovery state.

## Pages in this group

- [Server health check](backend-healthcheck.md) is the smallest diagnostic.
- [Node administration](node-administration.md) explains node-wide identity and
  Space creation responsibilities.
- [Operations](operations.md) covers backups and upgrades.

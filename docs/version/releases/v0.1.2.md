title: "Ugoite v0.1.2 — Safer everyday workflows"
---

Ugoite v0.1.2 is the final planned 0.1.x patch before the v0.2 Product UX
work. It makes existing Ugoite workflows easier to navigate and safer to use
without changing the Space 0.1 data contract.

## Highlights

- CLI commands can use a selected context, so everyday Space operations no
  longer need to repeat connection and Space details.
- Browser Entry editing uses more consistent typed controls and clearer
  Knowledge-first navigation across Entries, Assets, Forms, Search, History,
  and Settings.
- Delete, restore, and conflict flows are safer: destructive actions are
  confirmed, referenced Assets are protected, and edit conflicts preserve the
  local draft.
- Authentication and invitation flows include additional recovery and focus
  fixes.

## Upgrade

- No Space migration is required from v0.1.1; existing Spaces remain
  compatible.
- Legacy explicit CLI Space arguments and raw Markdown authoring remain
  supported 0.1.x paths.

title: "Ugoite v0.1.1 — Structured Knowledge baseline"
---

Ugoite v0.1.1 is the stable v0.1 Knowledge baseline for local-first teams and
operators running the server-backed browser workflow.

## Highlights

- Structured browser Entry editing through Form fields, Preview, and the
  advanced Source path.
- Durable Change IDs in CLI mutation receipts for create, update, delete, and
  restore operations.
- A Rust-centered workspace, local CLI core mode, one non-root runtime image,
  and the supported server-backed browser behavior.
- Documentation that distinguishes shipped behavior from planned browser-local
  synchronization and other future capabilities.

## Upgrade

The v0.1.1 product patch keeps Space compatibility at 0.1. Existing Spaces
remain usable, and legacy Markdown authoring remains available alongside
structured Entry authoring.

Remote CLI asset upload is outside the supported v0.1.1 documentation surface;
core mode remains the local asset path.

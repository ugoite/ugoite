---
title: 'v0.2 roadmap'
---

**Status:** planned

The next stream expands the product without changing ownership of user data.

Planned themes include:

- browser-local Space persistence and optional synchronization/relay behavior;
- user-controlled query-backed views;
- broader MCP resources and carefully governed tools/prompts;
- vector, voice, and computational workflows where trust and portability are explicit.

None of these items is shipped merely because it appears in a roadmap. The current browser remains server-backed and MCP v1 remains the small stable semantic facade described in `api/mcp.md`.

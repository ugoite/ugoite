---
title: 'v0.2 product capabilities'
---

**Status:** planned

The next stream is the first product realization of the v0.1 North Star. It
expands user-controlled Experience without changing ownership or authority of
user data.

Planned capabilities include:

- browser-local Space persistence and optional synchronization/relay behavior;
- declarative, query-driven, saved, and shareable View/Application Definitions;
- bounded actions and human-created or agent-assisted Experience composition;
- broader MCP resources and carefully governed tools/prompts;
- vector, voice, and other AI-assisted workflows where authorization, trust, and
  portability are explicit.

Definitions that become durable remain ordinary Space-owned Knowledge. Rendered
state, transient query results, and execution state remain Experience runtime
state. v0.2 does not assume arbitrary JavaScript/Python execution, package
installation, an app-specific backend/database, or a parallel authorization
authority.

None of these items is shipped merely because it appears in a roadmap. The current browser remains server-backed and MCP v1 remains the small stable semantic facade described in `api/mcp.md`.

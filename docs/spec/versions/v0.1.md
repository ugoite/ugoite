title: 'v0.1 release stream'
---

**Status:** in progress

## Implemented foundation

- eight-crate Rust workspace and Deno frontend/docsite/e2e workspace;
- operator-owned Space storage, append-only revisions, Forms, assets, search, saved SQL, and SQL sessions;
- local CLI core mode and remote CLI mode;
- Axum REST server, server-backed browser, and one read-only MCP resource;
- one non-root runtime image, Compose files, Helm chart, and local release-validation task;
- authentication with static/signed credentials, session cookies, development mock OAuth, and Space membership roles.

## Incomplete v0.1 work

- `/auth/login` passkey/TOTP implementation;
- managed service-account lifecycle and audit-log APIs;
- repository automation that publishes signed/checksummed image and CLI artifacts;
- post-publish quick-start verification and final supported release notes.

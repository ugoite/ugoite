**Draft status:** proposed scope only. v0.2.1 has not been prepared or released.
This page is not the stable manual release note; the final note will be created
only after the acceptance gates report outcomes for one exact candidate SHA.

## Proposed scope

The v0.2.1 plan proposes clearer write outcomes, operator-verifiable Spaces,
portable recovery, more dependable read cancellation and SQL export, measured
startup recovery, verified S3-compatible storage, MCP conformance, and
cross-surface product journeys. The final release note will list only changes
that are implemented and supported by their acceptance evidence.

The current acceptance definitions and limits are in the
[product journey and evidence index](v0.2.1-product-journeys.md) and the
[cross-surface journey matrix](../testing/cross-surface-acceptance.md#product-journeys-for-the-v021-candidate).
Those documents do not claim that every proposed capability exists or has passed
its gate.

## Compatibility boundary

The plan is intended to preserve existing v0.2 normal workflows and `0.1` Space
compatibility. No release decision is recorded here. Any discovered change that
makes existing Space data unreadable, removes a supported normal API/CLI path,
or requires a migration must be reviewed against the release compatibility
policy before the scope is finalized.

## Not in this release plan

Browser-local persistence and offline-first synchronization, MCP Tasks and Apps,
View/Application Definitions, and an arbitrary code runtime remain outside this
plan.

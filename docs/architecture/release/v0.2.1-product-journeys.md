This page is the L13/L14 acceptance and public-claim index for the proposed
v0.2.1 scope. It is not a release note or release approval. The prepared version
remains 0.2.0 until a separate release decision, and claims stay conditional
until their gates have evidence tied to one exact candidate SHA.

## Run record fields

The evidence record for each acceptance selector contains:

- exact source SHA and fixture name or seed;
- command, exact selector, surface, and transport;
- environment and expected result;
- actual result, exit code, and artifact location;
- remaining unverified scope.

Static source references are locators only. Mocked or unit evidence is labeled
as such, and real-server, Browser, CLI core, CLI remote, and manual evidence are
recorded independently. Evidence from different SHAs is not combined into a
single candidate result.

## Release-note readiness

The v0.2.1 stable release note is intentionally not finalized in this change.
The implementation plan assigns the underlying feature and release gates to
other lanes. Once those gates have recorded their outcomes, the release note can
state only the claims supported by the same candidate SHA, with the known limits
and planned features identified explicitly. The integrated journey run and its
evidence record are tracked by
[#3240](https://github.com/ugoite/ugoite/issues/3240). The separate
[release note draft](v0.2.1-release-note-draft.md) records the proposed scope
while keeping those claims conditional.

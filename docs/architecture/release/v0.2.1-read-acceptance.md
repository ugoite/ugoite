## Compatibility review

The accepted work preserves existing Space data and does not require migration.
It adds read lifecycle protection, virtual rendering and its acceptance
coverage, and bounded export failure coverage without removing documented CLI
inputs or introducing a new REST operation. Browser abort evidence is kept
separate from server-side query execution and authorization evidence.

## Outstanding acceptance

Keep #3148 open until a real VoiceOver or NVDA run records the required
interaction matrix, environment, and evidence. Do not describe the virtual table
as screen-reader verified before that run. Credential expiry acceptance is
recorded; the prepared repository version remains 0.2.0, and this work does not
prepare or publish a release.

# Prerelease Composition graph snapshot

The YAML and UI component files in this directory preserve the exact prereplacement
Composition source at base commit `7f782d29d1d31558a610e7dfdd6c7756ef370ebf`.
They are historical records only; they are outside the active Mitase inventory and
are not current acceptance criteria or implementation claims.

The prerelease Composition v1 source grammar and Studio contract were replaced
before release. The active target is documented in [ADR-024](../../../contracts/adr-024-composition-sql-first.md),
[the Composition contract](../../../contracts/composition.md),
[the acceptance gap matrix](../../composition-acceptance.md), and the active
Mitase requirements `REQ-COMP-008`, `REQ-FE-079`, and `REQ-FE-080`.

This snapshot preserves original requirement wording, criteria, statuses,
verification bindings, feature mappings, and policy evidence. Old verification
results describe the prereplacement implementation and do not establish any
SQL-first requirement. SQL-first runtime, browser, mobile, accessibility, and
recovery acceptance remains unverified until its implementation and focused
checks are complete.

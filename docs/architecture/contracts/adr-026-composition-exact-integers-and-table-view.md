**Status: Exact-integer decision retained. Table presentation superseded
before release by [ADR-027](adr-027-text-first-composition.md).**

Composition supports signed 64-bit SQL integer values without rounding.
[The current contract](composition.md#canonical-document) defines the token
and transport rules. Tables render the ordered SQL projection defined by
ADR-027.
